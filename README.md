# SpendLens — A second opinion on your AI bill

Free audit of startup AI tool spend (Cursor, Claude, Copilot, ChatGPT, Anthropic API, OpenAI API, Gemini, Windsurf). Defensible, citation-backed recommendations. No login.

This is the Round 1 deliverable for the Credex Web Dev Intern application. Full README lands later in the week as the build solidifies.

## Quick start

```bash
pnpm install
cp .env.example .env.local   # fill values
pnpm dev                     # http://localhost:3000
```

## Verify

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```
